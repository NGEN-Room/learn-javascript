# Quiz – Conditionals

1. What symbol means “strictly equal to” in JavaScript?
===
2. What does this code print?
```javascript
let age = 12;
if (age >= 13) {
  console.log("Teen");
} else {
  console.log("Too young");
}
```
Too young.
3. What does `!==` check?
"strict inequality". 
4. What keyword ends a `switch` case?
break.
