


# Challenge – Playing with Strings

## 🧠 Goal:
Practice creating strings, using interpolation, and experimenting with string methods.

---

## 🔧 Instructions

1. Create a new folder called `challenge-3`.
2. Inside it, make two files:
   - `index.html`
   - `script.js`
3. Link your `script.js` file inside `index.html` using a `<script>` tag.
4. In your `script.js`, do the following:
   - Create two string variables: your **first name** and **last name**.  
   - Use string interpolation to combine them into a `fullName` variable.  
   - Print a greeting that says: *"Kia ora, [fullName]!"*.  
   - Create a sentence about your favorite hobby (e.g. `"I love playing rugby"`).  
   - Use at least 3 string methods on that sentence (`.toUpperCase()`, `.includes()`, `.length`, `.trim()`, etc).  

---

## ✅ Bonus Challenge
- Print your `fullName` in all caps.  
- Check if your `fullName` includes the letter `"a"`.  
- Show how many characters are in your hobby sentence.  

---

## ▶️ How to Run
Open your `index.html` file in the browser → Right-click → Inspect → Console → See your output!

---

👉 This challenge reinforces:  
- Creating and combining strings  
- String interpolation  
- Using common string methods  
- Practicing immutability (methods return new strings, they don’t change the original)
