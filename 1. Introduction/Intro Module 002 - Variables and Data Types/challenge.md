


# Challenge – Working with Variables

## 🧠 Goal:
Practice declaring variables with `let` and `const`, understanding data types, and using `typeof`.

---

## 🔧 Instructions

1. Create a new folder called `challenge-2`.
2. Inside it, make two files:
   - `index.html`
   - `script.js`
3. Link your `script.js` file inside `index.html` using a `<script>` tag.
4. In your `script.js`, do the following:
   - Create a variable for your **first name**.  
   - Create a variable for your **age**.  
   - Create a variable that stores whether you are a **student** (`true`/`false`).  
   - Use `console.log()` to print each variable.  
   - Use `typeof` to print the type of each variable.

---

## ✅ Bonus Challenge
- Create a variable with `let` and then change its value. Print it again.  
- Create a variable with `const` and try to change its value. What happens?  

---

## ▶️ How to Run
Open your `index.html` file in the browser → Right-click → Inspect → Console → See your output!

---

👉 This challenge reinforces:  
- Declaring variables with `let` and `const`  
- Using different primitive data types (string, number, boolean)  
- Checking types with `typeof`  
- Understanding the difference between `let` and `const`
