

# Challenge – My First Website Log

## 🧠 Goal:
Practice linking JavaScript to an HTML file and using multiple `console.log()` statements.

---

## 🔧 Instructions

1. Create a new folder called `challenge-1`.
2. Inside it, make two files:
   - `index.html`
   - `script.js`
3. Link your `script.js` file inside `index.html` using a `<script>` tag.
4. In your `script.js`, do the following:
   - Print your **name** in the console.  
   - Print your **favorite hobby**.  
   - Print your **favorite food**.  
   - Print a sentence that combines them all (e.g. *“Hi, I’m Alex. I love football and my favorite food is pizza!”*).

---

## ✅ Bonus Challenge
- Add one more `console.log()` that prints today’s date.  
- Try changing one of your variables and re-run the code. What happens?  

---

## ▶️ How to Run
Open your `index.html` file in the browser → Right-click → Inspect → Console → See your output!

---

👉 This challenge reinforces:  
- File structure  
- Linking JS to HTML  
- Using multiple `console.log()` statements  
- Storing/reusing values with variables (a preview of Lesson 2!)
